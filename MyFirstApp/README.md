# MyFirstApp

A React Native app built with Expo for the reusable components lab exercise.

## Setup and run

1. Install the current Node.js LTS release from <https://nodejs.org>.
2. Open PowerShell in this folder and install the project dependencies:

   ```powershell
   npm install
   ```

3. Start Expo:

   ```powershell
   npm start
   ```

4. Install Expo Go on an Android or iOS device and scan the QR code. To use an
   Android emulator instead, start the emulator and run `npm run android`.

The project uses Expo's built-in CLI through the `expo` package; a separate
global `expo-cli` installation is not needed.

## Project files

- `App.js` renders the app's home screen.
- `components/Header.js` contains the reusable green app header.
- `components/Footer.js` contains the app footer.
- `components/WelcomeMessage.js` displays the student's name and section.
- `screens/HomeScreen.js` composes the header, welcome message, and footer.
- `index.js` registers the root component with Expo.
- `package.json` defines the app dependencies and run scripts.
- `app.json` contains Expo app metadata.
- `babel.config.js` configures Expo's JavaScript transpiler.
- `assets/` is for images, icons, and other app assets.
- `node_modules/` is generated by `npm install` and contains dependencies.

## Customize the exercise

In `screens/HomeScreen.js`, change the `name` and `section` props passed to
`WelcomeMessage` to your own details. Try a different `backgroundColor` in
`components/Header.js` and a different text `color` in `components/Footer.js`.
Save and check the live preview.
